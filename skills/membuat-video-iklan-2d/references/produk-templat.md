# Templat profil produk

Salin ke `references/produk-<nama>.md` dan isi bersama owner. Tanyakan hanya bagian yang belum diketahui.

```
# Profil produk: <nama>

<apa produknya, harga/paket, platform jualan>

## Avatar
<siapa, usia, situasi, rasa sakit, bahasa sehari-hari, keberatan>

## Mass desire · UMP · UMS
<dari copy acuan owner; lihat copy-acuan.md>

## Aturan khusus
- Sapaan: <Ibu / kamu / Kak …>
- CTA per platform: <kalimat persis + tombol>
- Kata/klaim yang dilarang: <…>
- Tokoh: <narator, tokoh pendukung>

## Visual
- Palet: <warna merek + warna latar; fokus kontras>
- Aset asli produk: <file>

## Folder
- Naskah: <…>
- Final: <…>
```
